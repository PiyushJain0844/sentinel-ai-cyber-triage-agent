# SENTINEL AI — Screenshot Gallery Guidelines

This directory stores visual walkthrough assets for the SENTINEL AI platform.

### Required Screenshot Assets

Place 1920x1080 (or standard 16:9) PNG captures with the following filenames:

| Filename | View | Description |
| :--- | :--- | :--- |
| `login.png` | Dedicated Login Page | Two-column desktop authentication view with branding and demo login buttons. |
| `dashboard.png` | Main SOC Dashboard | Overview KPI cards, telemetry volume chart, severity profile, and live feed. |
| `monitoring.png` | Live Threat Monitoring | Real-time security events feed with multi-filter search and raw log inspector. |
| `incidents.png` | Incident Management | Entity-grouped incident cards with risk scores, MITRE ATT&CK tactics, and status badges. |
| `investigation.png` | Attack Investigation | Interactive React Flow kill-chain graph with evidence findings citing concrete event IDs. |
| `agents.png` | AI Agent Activity | Real-time operational status, execution metrics, and latency of all 6 agents. |
| `responses.png` | Response Center | Remediation queue with human-in-the-loop approval and execution simulation. |
| `verification.png` | Verification Center | Closed-loop verification records, 4 automated checks, and failure simulation probe. |
| `settings.png` | Platform Settings | Engine status, Gemini AI mode / deterministic fallback, and SQLite database counters. |

> **Note**: In the main `README.md`, image tags link to these files using relative paths (`docs/screenshots/<filename>.png`).
